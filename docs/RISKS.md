# RISKS

The brief (§4) requires at least these risks: hallucinations, source bias, privacy, prompt injection, availability and abuse.

| Risk | What can go wrong | Mitigation in the system | Residual risk |
|---|---|---|---|
| **Hallucination** | The model states facts or quotes that aren't in the sources | The judge sees only retrieved passages. Every quote is verified by code against its passage. Unverified quotes, unknown source ids and uncited factual sentences are dropped. Decisive verdicts need a verified backing quote, otherwise the claim abstains | A *real* quote can be used out of context (wrong stance). Measured by the manual citation review (`eval/manual_review.tsv`) |
| **Source bias / coverage** | The catalog is mostly government sources. Silence isn't evidence | An open, auditable catalog (`/v1/sources`) with qualification and exclusion rules. Tier C can never decide alone. The answer always says that a missing source doesn't mean the claim is false. Archival material is flagged | Topics outside the catalog get "brak wystarczających dowodów". Official sources can be wrong or slow |
| **Privacy** | Users paste personal data. Logs leak it | PII masking before the LLM and before storage. Data minimization (masked input only; images aren't stored). 30-day retention. `DELETE /v1/sessions/{id}`. Provider data collection is denied on OpenRouter | Names aren't masked yet. OpenRouter is a US intermediary (EU-only option: `mistral` or `ollama`) |
| **Prompt injection** | Instructions in the user text, fetched pages or corpus documents change the system's behaviour | Data blocks with random per-call delimiters. No tools for the model. Strict JSON schema. Code decides citations and gates. Detection logs `injection_attempt` and shows a notice | New phrasing can slip past detection. The structural defences still limit the impact to the wording of a single explanation |
| **Availability** | LLM, OCR or fetch outages, rate limits, a missing key | Each one maps to a `technical_error` / `rate_limited` status with "To nie jest ocena prawdziwości", never a verdict. Retrieval and OCR are local | A single process and in-memory rate limits for now (`docs/TODO.md`) |
| **Abuse** | Spam, cost exhaustion, SSRF through URL checks, using the service to "launder" claims | Per-session and per-client rate limits, input size limits, the SSRF guard (public IPs, ports 80/443, checked on redirects), robots.txt. Admin endpoints need a token. The UI never claims more certainty than the gates allow | A DNS-rebinding window in the SSRF check. Distributed abuse needs an upstream rate limit |
| **False handoff** | Telling the user their report reached a moderator when it didn't | `przekazano_moderatorowi` only after a confirmed 2xx delivery; otherwise `zalecamy_przekazanie` | None known |
| **Verdict from metadata** | Deciding a claim from its domain, author or sanctions status | Incident matches and source status are context notices only. The gates only consider verified quotes | None known |
